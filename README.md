# CartPilot — Zepto Shopping Assistant

Free Netlify-ready shopping list validator with a ₹100 per-item limit.

## Hosting

Connect this GitHub repository to Netlify; deploy the `public/` directory without a build command.

## Important limitation

This static app supports import, local price validation, skip alerts and automatic inclusion of items priced ₹100 or less. It **does not** fetch live prices from Zepto or add products to a real Zepto cart. Live orders require an authorized integration.
